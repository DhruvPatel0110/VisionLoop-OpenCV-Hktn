Grounded Evaluation Methodology

Mathematical formulation of Ground Truth F1, morphological tolerance dilation, and proxy metrics.

1. Ground Truth F1 Score

For images with verified ground-truth references, we calculate Precision and Recall using a 1-pixel morphological tolerance window (BSDS standard practice):

Precision = |E_cand ∩ Dilate(E_ref, 1px)| / |E_cand| Recall = |E_ref ∩ Dilate(E_cand, 1px)| / |E_ref| F1 = 2 × (Precision × Recall) / (Precision + Recall)

2. Unlabelled Proxy Quality

For unlabelled images where reference edge maps are unavailable, three proxy metrics prevent degraded configurations:

  • Edge Continuity: Connected components ratio penalizing fragmented edge dust.
  • Noise Ratio: Fraction of isolated single-pixel edge noise.
  • Density Fitness: Checks that edge density stays within natural boundaries (0.5% - 10%).

3. High-Precision Timing Harness

To eliminate CPU thermal throttling and operating system scheduler jitter:

T_candidate = Median(Pass_1, Pass_2, ..., Pass_5) after 3 Warmup passes
